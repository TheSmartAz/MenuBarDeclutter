# v0.1.1 Product Diet

> Historical note: this document records the Phase 14 / `v0.1.1` product diet. It is not current-facing `v0.1.2` guidance. Use `docs/project-summary.md`, `docs/release/v0.1.2-release-notes.md`, and `docs/testing/manual-v0.1.2-results.md` for the active Phase 15 release state.

Phase 14 keeps MenuBarDeclutter on the `v0.1.1` release line and makes the product feel lighter without removing important power-user capability.

The focused product story is:

> MenuBarDeclutter helps you hide clutter, arrange icons safely, find hidden items when needed, and recover if layout breaks.

## Diet Goal

The normal app should feel understandable in about 60 seconds. Users should see a small set of everyday workflows first, then discover Preview, Labs, Experimental, and power-user features only when they need them.

The product diet does not delete existing capability by default. It changes what is treated as a main product pillar.

## Main Settings Shape

The main Settings sidebar should have no more than these seven top-level areas:

1. General
2. Hide & Reveal
3. Arrange
4. Find & Rescue
5. Privacy
6. Recovery
7. Advanced

Everything else should either move into one of those areas or become a nested Advanced subsection.

## What Stays Prominent

| Workflow | Why It Stays Prominent |
| --- | --- |
| Basic hide/reveal | This is the core product promise. |
| Auto-rehide and hover reveal | These are everyday behavior controls. |
| Always-hidden zone | It is part of the stable hiding model. |
| Basic hotkey | It belongs with core reveal behavior. |
| Launch at Login | It is basic setup, not an advanced feature. |
| Guided Manual Arrange | Icon placement is essential to successful hiding. |
| Find Icon | It helps users recover confidence when something is hidden. |
| Second Bar | It is a rescue and browsing surface, not a separate pillar. |
| Crowded reveal fallback | It supports rescue when the menu bar is too full. |
| Safe Mode, reset, diagnostics, health | Recovery must remain easy to find. |
| Privacy boundary | Users need to know what works before optional Pro gates. |

## What Moves Out Of The Main Flow

| Capability | New Home |
| --- | --- |
| Profiles | Advanced |
| Smart Triggers | Advanced |
| Dynamic Hotkeys beyond the Basic hotkey | Advanced |
| Private Access | Advanced |
| Advanced groups and group status items | Advanced |

| Spacing Labs | Advanced |

## Arrange Reframe

Icon placement should not feel like a risky experimental island. Phase 14 splits it into three clear layers:

| Layer | Status | User Promise |
| --- | --- | --- |
| Guided Manual Arrange | Stable | The app teaches the user how to place controls and separators with normal macOS Command-drag. |
| Placement Planner | Preview | The app suggests where items should go and produces manual instructions without moving anything. |
| Assisted Move | Experimental | The app can try one confirmed move when all gates pass, but it may fail and must offer recovery. |

Guided Manual Arrange is the recommended path. Placement Planner helps Pro users plan. Assisted Move remains optional and explicitly Experimental.

## Find & Rescue Consolidation

Find & Rescue should gather workflows that answer "Where did my icon go?" or "How do I get it back?"

It should include:

- Find Icon
- Second Bar
- crowded reveal fallback
- New Item Inbox
- lightweight groups, tags, and saved collections
- reveal, highlight, and open-owning-app actions
- manual arrange instructions for selected items
- Assisted Move entry points only when clearly labeled Experimental

Search and Second Bar should no longer read as separate top-level product pillars.

## Advanced Role

Advanced is not a junk drawer. It is the home for capability that is useful but not part of the everyday first-run story.

Every Advanced card should show:

- feature name
- status badge
- short purpose
- requirements or gates
- link to detailed controls
- disable or reset action when useful

Advanced should make it clear that Basic hiding and Guided Manual Arrange do not depend on these features.

## Acceptance Checklist

- Historical v0.1.1 docs use `v0.1.1`; current-facing docs should use the active release line.
- Main Settings language maps to General, Hide & Reveal, Arrange, Find & Rescue, Privacy, Recovery, and Advanced.
- Arrange is a first-class product area.
- Guided Manual Arrange is Stable and permission-free.
- Placement Planner is Preview and non-mutating.
- Assisted Move is Experimental and confirmed per action.
- Preview, Labs, Experimental, and Internal features are not presented as stable product pillars.
- Recovery remains easy to reach.
- No current-facing copy promises stable bulk movement, stable spacing mutation, stable competitor migration, or broad third-party control.
