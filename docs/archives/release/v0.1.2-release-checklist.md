## Release Blockers

- Any stable Basic Mode regression.
- Any automatic Accessibility prompt on launch or normal Settings open.
- Any Screen Recording, ScreenCaptureKit, Apple Events permission, Apple Events scripting/control of other apps, Input Monitoring, network telemetry, analytics, cloud sync, remote config, or private API dependency.
- Any current-facing claim that Assisted Move or bulk icon moving is stable.
- Any release artifact named as v0.2.
- Any unresolved `PENDING`, `PARTIAL-*`, `BLOCKED-PHYSICAL`, or `BLOCKED-HARDWARE` manual QA row for a stable Basic Mode claim, unless the claim is explicitly downgraded, scoped out, or deferred in release notes before shipping.
- Any `PARTIAL-INFRA` or `BLOCKED-INFRA` validation row without an equivalent narrower command that proves the same code/test surface.
