# v0.1.4 Known Limitations

- Workspaces are Preview/Foundation only.
- Function Bar, Info Strip, and Set Builder are not runtime features in this phase.
- Workspace switching changes only app-owned configuration state.
- Physical profile bindings are stored for future dry-run guidance and are not auto-applied.
- Group references can be stored, but full linked/detached editing arrives later.
- Menu bar item proxy references are data only unless later preview features resolve them.
- No system menu bar replacement, pixel capture, Screen Recording, ScreenCaptureKit, online widgets, cloud sync, or stable third-party activation is included.
