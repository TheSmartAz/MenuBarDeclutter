# v0.1.3 Release Runbook

This runbook is for the current local/internal v0.1.3 alpha release rehearsal. Developer ID export, notarization, stapling, and notarized Gatekeeper acceptance are deferred public-distribution gates and are not required for this checkpoint. They must only be recorded as passing when real credentials are available and the Apple notarization flow succeeds.

## Preconditions

- Xcode command line tools point at the intended Xcode.
- Working directory is the repository root.
- No secrets, certificates, app-specific passwords, or notarization profiles are committed.
- App version is `0.1.3` and build is `4`.

Check version/build:

```sh
xcodebuild -scheme MenuBarDeclutter -destination 'platform=macOS' -showBuildSettings | rg 'MARKETING_VERSION|CURRENT_PROJECT_VERSION'
```

## Local Dry Run

Run:

```sh
bash -x scripts/build_release.sh --dry-run
```

Expected outputs:

- `build/Export/MenuBarDeclutter.app`
- `build/Dist/MenuBarDeclutter-v0.1.3.zip`
- optional alpha dry-run package when alpha packaging is enabled

Then verify the exported app:

```sh
APP_PATH="$PWD/build/Export/MenuBarDeclutter.app" bash scripts/verify_release_artifact.sh
```

Dry-run artifacts are not notarized. Expected warnings are limited to non-notarized Gatekeeper/stapler results. For the local/internal alpha checkpoint, these warnings are acceptable when the verifier classifies them as expected dry-run warnings. Do not treat missing notarization as public-distribution success.

## Installed-App Dry Run

Run:

```sh
bash scripts/build_release.sh --dry-run --install --verify-installed
```

Expected behavior:

- archive and export complete
- package verification passes
- local install to `/Applications/MenuBarDeclutter.app` completes
- installed app verification passes
- dry-run notarization warnings remain explicit

If the process is killed by local infrastructure, record the exact exit code and rerun once after confirming no stale verifier process is still active.

## Deferred Public Distribution Notarization Path

Only run this for a public notarized distribution candidate when Developer ID credentials and the notarization keychain profile are available on the machine:

```sh
scripts/build_release.sh --notarize --staple --install --verify-installed
```

Expected real-flow checks:

- strict codesign passes
- hardened runtime is present
- sandbox entitlement is absent for the assistive Pro Accessibility Discovery build
- no network entitlement is present
- `LSUIElement` remains configured
- app category remains configured
- URL scheme remains configured
- no sensitive usage strings are introduced
- ScreenCaptureKit is not linked
- stapler validation passes after notarization
- Gatekeeper assessment passes after notarization

If credentials are unavailable, record the blocker as external credentials unavailable. Do not fake notarization, stapling, or Gatekeeper success.

## Required Privacy Check

Run:

```sh
scripts/verify_privacy_boundary.sh
```

For built-app checks:

```sh
APP_PATH="$PWD/build/Export/MenuBarDeclutter.app" scripts/verify_privacy_boundary.sh
```

Basic Mode must remain free of Accessibility prompts, Screen Recording, Apple Events, Input Monitoring, network access, telemetry, analytics, cloud sync, and private menu bar APIs.
