- Any overclaim that Assisted Move, bulk moving, broad third-party activation, visual capture, competitor import, cloud sync, telemetry, or private menu bar behavior is stable.

## Deferred Public Distribution Gate

Public notarized distribution still requires a usable Developer ID Application signing identity with private key in the keychain Xcode uses, in addition to notarization credentials. The local `-allowProvisioningUpdates` fallback did not resolve the missing identity on this machine.

The local-alpha main app build is intentionally non-sandboxed so Pro Accessibility Discovery can inspect menu extras after user opt-in. This does not add Developer ID/notarization, network entitlements, ScreenCaptureKit, Screen Recording, Apple Events, or Input Monitoring.
