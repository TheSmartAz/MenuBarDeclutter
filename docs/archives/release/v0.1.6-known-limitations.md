# v0.1.6 Known Limitations

- Set Builder remains Preview.
- Drag/drop support is limited and should be treated as preview-only.
- Menu bar item proxies depend on Pro Discovery metadata and do not provide stable broad activation.
- Linked Group editing warnings are basic and should be expanded in later phases.
- Info Strip runtime is deferred to v0.1.7.
- Physical workspace switching, automatic profile application, bulk icon moving, and system menu bar replacement are not implemented.
