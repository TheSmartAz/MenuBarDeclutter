# v0.1.8 Known Limitations

- Workspace Integration is Preview.
- Assignment affects only MenuBarDeclutter-owned local configuration.
- Find Icon Workspace filters require a current Workspace usage index; when unavailable, Workspace-specific filters intentionally degrade to no matches instead of inventing assignments.
- Physical profile binding remains preview/dry-run oriented and never moves real menu bar items automatically.
- Manual QA was deferred to the v0.1.9 Design RC pass.
