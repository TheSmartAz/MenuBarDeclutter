# MenuBarDeclutter v0.1.7 Release Notes

This release completes the v0.1.4-v0.1.7 preview track for Workspaces, Function Bar, Set Builder, and Info Strip.

## Added

- Local Workspaces store with validation, repair, backups, switching, and default sets.
- Hidden Workspaces Preview settings page under Advanced.
- App-owned Function Bar Preview with Set Switcher and Command Center-routed actions.
- Set Builder draft editor for workspace composition and linked/detached group references.
- App-owned Info Strip MVP with local-only tiles and rotation.
- Preview-safe diagnostics and import/export coverage for new settings.

## Privacy

- Basic Mode remains permission-free.
- Preview panels do not capture the screen, inspect pixels, call private APIs, or use the network.
- Pro-dependent item proxies and tiles degrade when permissions or opt-ins are unavailable.

## Known Limitations

- Preview panels are not a full menu bar replacement.
- Menu bar item proxies depend on existing Pro Discovery gates.
