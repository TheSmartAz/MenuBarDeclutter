# v0.1.5 Known Limitations

- Function Bar is Preview and remains under Advanced/Workspaces Preview.
- It is not a live clone of the system menu bar.
- Proxy items can reveal/highlight through existing safe commands but broad third-party activation is not stable.
- Info Strip runtime is deferred to v0.1.7.
- Full Set Builder drag/drop and linked/detached group editing are deferred to v0.1.6.
- Primary-click Function Bar behavior is off by default.
- Physical workspace switching and bulk icon moving are not implemented.
