# v0.1.3 Public Claims

Use this product message:

> MenuBarDeclutter is a privacy-first menu bar declutter tool. Hide clutter without sensitive permissions, arrange icons safely, find hidden items when needed, and recover if layout breaks.

## Stable Or Near-Stable Claims

These claims are allowed for v0.1.3 when linked to the current automated evidence and pending/manual QA status:

- Basic hide/show/reveal behavior works without sensitive permissions.
- Basic Mode does not request Accessibility, Screen Recording, Apple Events, Input Monitoring, or network access.
- Guided Manual Arrange uses normal macOS Command-drag behavior.
- Auto-rehide, hover reveal, always-hidden reveal, and Basic hotkey are part of the v0.1.3 stable target pending physical QA.
- Safe Mode, recovery actions, reset layout, and diagnostics export are local recovery tools.
- Diagnostics export is privacy-safe by default and excludes screenshots, screen contents, live search text, selected item identity, protected names, protected hotkey targets, active unlock sessions, and network data.
- Local MenuBarDeclutter backup/restore packages are schema-versioned, privacy-safe by default, dry-run before apply, create a backup immediately before mutation, and roll back on apply failure.
- Find Icon reveal/highlight can be claimed when Pro Mode, Accessibility Discovery, and macOS Accessibility permission are all satisfied.
- Second Bar metadata/icon browsing can be claimed when Pro Mode, Accessibility Discovery, and macOS Accessibility permission are all satisfied.

## Preview Claims

These should be labeled Preview:

- Find & Rescue ranking and recovery workflows.
- Crowded Reveal Rescue fallback.
- Second Bar item browsing and item actions.
- Pro Placement Planner.
- New Item Inbox.
- Collections/groups inside Find & Rescue.
- Basic Shortcuts actions and gated advanced Shortcuts status.
- Import/Export migration assistant UI.
- Profiles, Smart Triggers, Dynamic Hotkeys, Private Access, groups, App Intents automation, and URL automation.

## Experimental Claims

These must be labeled Experimental:

- Assisted Move actual execution.
- Icon moving beyond manual Command-drag guidance.
- Broad item activation where present.

## Forbidden Claims

Do not claim:

- stable bulk icon moving
- stable broad activation of arbitrary third-party menu extras
- live menu bar pixel capture
- Screen Recording-free visual duplication of real menu icons
- ScreenCaptureKit use
- Private Access encryption
- Private Access hiding already-visible third-party icons
- Touch ID or device authentication hiding visible third-party items
- stable Bartender, Ice, SaneBar, or competitor migration
- cloud sync
- telemetry, analytics, crash upload, remote config, or network behavior
- future-release content or future-release availability
