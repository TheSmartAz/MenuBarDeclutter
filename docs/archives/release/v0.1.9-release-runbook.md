# v0.1.9 Release Runbook

1. Confirm `Config/Shared.xcconfig` reports `MARKETING_VERSION = 0.1.9` and `CURRENT_PROJECT_VERSION = 10`.
2. Run `xcodebuild -scheme MenuBarDeclutter -destination 'platform=macOS' build`.
3. Run `xcodebuild test -scheme MenuBarDeclutter -destination 'platform=macOS'`.
4. Run source/config privacy checks before any release artifact is shared.
5. Use `scripts/build_release.sh --dry-run` for local alpha packaging.

Developer ID export, notarization, stapling, and public distribution are not part of the current scope.
