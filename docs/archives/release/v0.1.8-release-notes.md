# MenuBarDeclutter v0.1.8 Release Notes

v0.1.8 is the Workspace Integration Pack. It connects the existing Preview Workspaces track to Find & Rescue, New Item review, placement hints, crowded rescue, diagnostics, and local import/export.

## Added

- Workspace usage index for app-owned Workspace item references and linked/detached Group references.
- New Item assignment service for adding hashed item references to Workspaces or Groups.
- Workspace-aware Find Icon filters and badges.
- Workspace-aware placement recommendation adapter.
- Function Bar preference for crowded rescue fallback.
- Physical profile binding preview planner that never moves real menu bar items automatically.
- Workspace integration diagnostics with privacy-safe redaction.

## Privacy

- Basic Mode remains permission-free.
- New integration state is local-only.
- No screen pixels, screenshots, network data, telemetry, private APIs, or other-app control were added.
