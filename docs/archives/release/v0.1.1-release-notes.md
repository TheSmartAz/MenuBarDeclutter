# MenuBarDeclutter v0.1.1 Release Notes

MenuBarDeclutter `v0.1.1` is a release confidence and trust hardening update for the `v0.1` line. It keeps Basic Mode as the stable, permission-free core and tightens release identity, packaging, privacy verification, and public claims.

## Stable Core

- Basic Mode remains permission-free and based on public `NSStatusItem` behavior.
- Expand, collapse, reveal-all, auto-rehide, hover reveal, always-hidden reveal, global visibility hotkey, diagnostics export, Launch at Login, Safe Mode, and recovery remain the stable product surface.
- Pro Accessibility Discovery remains explicitly gated by Pro Mode, Accessibility Discovery, and macOS Accessibility permission.

## Native macOS Redesign

- Settings now uses a native macOS sidebar-and-detail structure with consistent page chrome, toolbar search, clear page summaries, and status badges for Stable, Preview, Labs, Experimental, Basic Mode, Pro Mode, Privacy Safe, and permission-required states.
- General, Menu Bar Items, Behavior, Layout, Search, Second Bar, Groups, Hotkeys, Profiles, Automation, Privacy, Private Access, Import / Export, Diagnostics, and Advanced were rebuilt around reusable native sections, value rows, requirements blocks, and recovery actions.
- Pro and permission-dependent pages now show degraded states without weakening Basic Mode. Basic Mode remains useful when Pro Mode, Accessibility Discovery, and elevated macOS permissions are all off.
- Diagnostics save/export actions were hardened after installed-app QA found an AppKit/SwiftUI save-panel re-entrancy crash.

## Release And Trust

- Active app version is `0.1.1` with build `2`.
- Release tooling now produces `MenuBarDeclutter-v0.1.1.zip` and dry-run alpha artifacts named `MenuBarDeclutter-v0.1.1-alpha.zip`.
- Developer ID export options and notarization support are present without committing credentials.
- Dry-run builds work locally without Developer ID or notary credentials.
- Artifact verification checks bundle identity, version/build, `LSUIElement`, sandbox, hardened runtime, URL scheme, app category, sensitive usage strings, network entitlements, code signature, ScreenCaptureKit linkage, and notarization/stapling status where required.

## Privacy

MenuBarDeclutter does not use Screen Recording, ScreenCaptureKit, Apple Events, Input Monitoring, network telemetry, analytics, crash upload, cloud sync, remote config, or private menu bar APIs.

Diagnostics exports exclude screenshots, screen contents, live search text, selected item identity, protected group names, protected hotkey targets, active unlock sessions, and import/export paths unless the user explicitly chooses related files.

## Feature Status

Stable features are documented in `docs/release/v0.1.1-feature-gates.md`.

Icon Moving remains Experimental. Smart Triggers, Dynamic Hotkeys, Private Access, group status items, App Intents automation, import/export migration, and crowded reveal rescue automation remain Preview unless later hardened. Menu Bar Spacing remains Labs.

## Import / Export Preview

Settings export now writes a real local JSON package with schema, app version, export kind, creation date, redaction mode, and intentionally omitted setting metadata. It no longer writes synthetic setting marker values.

Import now dry-runs first, creates a backup, and then offers an explicit safe apply action. Safe apply merges profiles, groups, hotkeys, and spacers by ID, skips conflicting dynamic hotkeys, leaves Launch at Login/Login Items system state unchanged, and does not enable Icon Moving, Smart Triggers, or Menu Bar Spacing Labs from an imported package. The Import / Export assistant can also restore the latest local backup as a merge-by-ID recovery path.

## Manual QA Pack

The release includes tester-facing manual QA docs for system behaviors that cannot be fully automated, including crowded menu bars, notch/external display layouts, sleep/wake, Login Items, permission grant/revoke, real Shortcuts surfaces, Private Access prompts, Labs, and Experimental Icon Moving.

The 2026-06-30 native redesign installed-app pass verified the dry-run installed app, every redesigned Settings page, diagnostics health export, URL scheme smoke behavior, network silence, Launch at Login enable/disable/restore, and expected Developer ID/Gatekeeper blockers for a non-notarized local artifact.
