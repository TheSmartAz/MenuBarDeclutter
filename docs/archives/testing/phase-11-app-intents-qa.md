# Phase 11 App Intents QA

## Steps

1. Open Settings > Automation.
2. Confirm App Intents are enabled by default.
3. Disable App Intents and run a Shortcut command.
4. Re-enable App Intents.
5. Run expand, collapse, reveal all, Second Bar, and Full Menu Bar Mode commands.
6. Try profile apply while profile access is disabled.
7. Enable profile access and try again.
8. Try Labs access while Labs access is disabled.
9. Enable Labs access and try again.
10. Enable Safe Mode and confirm only safe commands run.

## Expected

- No Apple Events prompt appears.
- Results are short and privacy-safe.
- Private Access and automation pause are respected.
