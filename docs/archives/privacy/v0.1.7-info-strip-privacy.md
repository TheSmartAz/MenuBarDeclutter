# v0.1.7 Info Strip Privacy

Info Strip is local-only by default. It does not use network widgets, weather/news/stocks, media private APIs, notification scraping, Screen Recording, ScreenCaptureKit, Apple Events scripting/control, Input Monitoring, telemetry, cloud sync, or private APIs.

Default tiles use local app state such as active Workspace, time, health counts, menu bar hidden counts, new item count, and stale scan status. Pro-dependent tiles degrade if Pro Discovery is unavailable.

Diagnostics report provider IDs, counts, state, timing, redacted Workspace IDs, and placement metadata. Raw workspace item names, raw menu bar item identities, protected group/workspace names, calendar/reminder titles, live search text, and file paths are excluded by default.
