# v0.1.6 Set Builder Privacy

Set Builder edits local app-owned Workspace data. It does not request Screen Recording, use ScreenCaptureKit, make network calls, use private APIs, or silently prompt for Accessibility.

Menu bar item proxy library entries require Pro Discovery metadata and degrade when Pro Discovery or Accessibility permission is unavailable.

Drag/drop payloads and diagnostics must avoid raw menu bar item names, bundle IDs, protected group names, protected workspace names, live search text, and file paths by default.

Imports/exports include Workspaces and linked/detached Group references in local JSON. Protected Groups are redacted in privacy-safe exports.
