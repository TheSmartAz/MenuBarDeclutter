# Profiles v0.1.1

Status: Preview.

Profiles apply local MenuBarDeclutter settings. Basic Mode remains usable without profiles, Pro Mode, Accessibility, or automation.

## Implemented

- Create, edit, duplicate, dry-run, apply, import, and export profile models.
- Dry-run summaries for items to reveal, move requirements, unavailable items, and permission requirements.
- Apply support for conservative local settings such as collapsed/start-collapsed, auto-rehide, hover reveal, Always Hidden, Second Bar, group status items, automation pause, layout suggestions, Full Menu Bar Mode, and Labs preferences when allowed.
- Command Center availability rows for profile apply.
- Profile apply through Command Center for App Intents, URL automation, dynamic hotkeys, Smart Triggers, and the Settings apply gate.
- Private Access can protect profile apply.

## Deferred

- Built-in Work/Home/Presentation template registry.
- Rich conflict resolver and manual override cooldown.
- Full trigger history UI and richer "why profile applied" explanations.
- Icon moving remains dry-run/requirement text unless the Experimental moving feature is explicitly enabled.
