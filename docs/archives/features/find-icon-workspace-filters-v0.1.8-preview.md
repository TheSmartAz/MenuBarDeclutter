# Find Icon Workspace Filters v0.1.8 Preview

Find Icon can show Workspace context when a usage index is available:

- Current Workspace.
- Any Workspace.
- Other Workspace.
- Unassigned.
- Groups.
- New Items.
- Stale.

Results can display local Workspace badges such as Current Workspace, Linked Group, Detached, New, Stale, and Unassigned. If no usage index is available, Workspace-specific filters degrade without inventing assignment state.
