# Workspaces v0.1.9 Preview

Workspaces are a top-level Preview settings area in v0.1.9.

Workspaces configure MenuBarDeclutter-owned Function Bar and Info Strip surfaces. They do not replace the macOS system menu bar, capture pixels, control other apps, move real menu bar icons automatically, or use the network.

The Workspaces page includes Preview gates, active Workspace status, Function Bar controls, Info Strip controls, Set Builder, and Workspace Integration diagnostics.
