# MenuBarDeclutter v0.2 Release Plan

Last reviewed: 2026-07-06

Status: draft plan. This is not a shipped release and does not change the
current active release line until v0.2 implementation is explicitly started.

## Goal

v0.2.0 is the Stable Workspaces Core plus Stable Pro Second Bar release.

Basic Mode remains the default product core: permission-free, local-first, and
recoverable. Second Bar becomes a Pro Stable feature only after explicit setup
and user opt-in.

## Confirmed Scope

Stable in v0.2:

- Basic Mode hide/reveal, Recovery, Diagnostics, Safe Mode, and Guided Manual
  Arrange.
- Workspaces Core:
  - Local Workspace create, duplicate, archive, switch, and repair.
  - Set Builder local Workspace editing.
  - Linked and detached Groups references.
  - Local persistence, validation, backup/restore behavior, and privacy-safe
    diagnostics.
- Second Bar Stable:
  - Large Second Bar panel.
  - Compact Strip.
  - Primary status item click routing to Second Bar / Compact Strip after
    explicit user enablement.
  - Accurate Icons rendered thumbnails.
  - Screen Recording dependency for Accurate Icons.

Preview in v0.2:

- Find Icon.
- Function Bar runtime.
- Info Strip runtime.
- Workspace Integration extras, including physical profile binding and richer
  crowded fallback behavior.
- Profiles, Smart Triggers, Dynamic Hotkeys, local automation, and advanced
  import/export flows.

Not opened in v0.2:

- Stable automated icon moving or bulk moving.
- Apple Events control or AppleScript dictionary.
- Input Monitoring.
- Network, cloud sync, telemetry, analytics, crash upload, remote config, or
  update checks.
- Private/offscreen menu bar item capture.
- Developer ID signing, notarization, stapling, or public distribution, unless
  separately requested.

## Product Rules

- Basic Mode must still work when Pro Mode is off, Accessibility is missing or
  revoked, Accurate Icons is off, Screen Recording is missing, and all Preview
  features are disabled.
- Basic Mode must not request Accessibility, Screen Recording, Apple Events,
  Input Monitoring, or network access.
- Second Bar Stable is a Pro feature. Its stable requirements are Optional Pro,
  Accessibility Discovery, Accessibility permission, Accurate Icons, and Screen
  Recording permission.
- Primary status item click must remain Basic hide/reveal by default.
- Primary status item click may open Second Bar / Compact Strip only after the
  user completes Second Bar setup and explicitly enables that routing.
- Workspaces Stable claims must describe local MenuBarDeclutter-owned
  configuration only. They must not imply system menu bar replacement, real
  icon movement, hidden system control, or physical profile mutation.
- Function Bar, Info Strip, and Find Icon must remain clearly labeled Preview
  in code, UI, release notes, support docs, and QA docs.

## Implementation Plan

1. Update v0.2 product taxonomy.
   - Add Workspaces, Function Bar, Info Strip, Set Builder, Accurate Icons, and
     Compact Strip to the current feature visibility taxonomy.
   - Make Stable / Preview / Labs / Experimental labels consistent in UI and
     docs.
   - Keep Advanced automation and Labs surfaces out of the main release
     headline.

2. Align Second Bar requirements.
   - Treat v0.2 Stable Second Bar as requiring Pro, Accessibility Discovery,
     Accessibility permission, Accurate Icons, and Screen Recording.
   - Update feature docs, support docs, privacy docs, release notes, onboarding,
     and setup copy to match that requirement.
   - Keep Basic Mode privacy copy clear that Basic Mode does not depend on
     Screen Recording.

3. Add explicit primary-click opt-in.
   - Keep default primary click on Basic hide/reveal.
   - Add a final setup control such as "Use menu bar icon for Second Bar".
   - Persist the setting separately from general Second Bar readiness.
   - Show requirements instead of silently changing behavior when readiness is
     missing or revoked.

4. Harden Second Bar Stable behavior.
   - Verify large panel and Compact Strip open, close, keyboard navigation,
     outside-click dismissal, Escape dismissal, and item selection.
   - Verify stale scan, no scan, permission denied, permission revoked, missing
     Accurate Icons, and missing Screen Recording states.
   - Verify panel and Compact Strip placement on built-in, notch, external
     display, active Space, wake, and display disconnect scenarios.
   - Verify Accurate Icons cache clear, reveal sweep behavior, stale thumbnail
     fallback, and app-icon fallback.
   - Verify Safe Mode suppresses Second Bar while keeping Basic controls and
     Recovery reachable.

5. Harden Workspaces Core.
   - Verify Workspace CRUD, switching, archival, default recreation, invalid
     data repair, and migration.
   - Verify Set Builder draft, commit, revert, autosave, linked group warning,
     and detached group behavior.
   - Verify Groups references survive missing, disabled, protected, linked, and
     detached states.
   - Verify diagnostics and exports report aggregate/redacted data only.
   - Keep Function Bar and Info Strip runtime behind Preview gates.

6. Update release tooling for v0.2.
   - Bump `MARKETING_VERSION` and build number only when implementation starts.
   - Replace v0.1-only artifact guards with v0.2-aware release guards.
   - Add v0.2 release notes, known limitations, release checklist, release
     runbook, local dry-run record, and manual QA result templates.
   - Keep release output as local/internal alpha zip unless public distribution
     is separately approved.

## QA Plan

Required automated gates:

```sh
xcodebuild -list
xcodebuild -scheme MenuBarDeclutter -destination 'platform=macOS' build CODE_SIGN_IDENTITY=- CODE_SIGNING_REQUIRED=NO
scripts/qa_preflight.sh
scripts/verify_privacy_boundary.sh
scripts/build_release.sh --dry-run --install --verify-installed
scripts/qa_installed_app_smoke.sh --app-path /Applications/MenuBarDeclutter.app
scripts/qa_network_watch.sh --installed
```

Required visual evidence:

- Settings pages.
- Privacy setup.
- Workspaces Core and Set Builder.
- Second Bar setup checklist.
- Large Second Bar panel.
- Compact Strip.
- Second Bar requirements states.
- Safe Mode / Recovery surfaces.

Required manual QA:

- Basic Mode fresh install, expand, collapse, reveal all, always-hidden reveal,
  reset layout, and Safe Mode recovery.
- Accessibility grant, deny, revoke, and rescan behavior.
- Screen Recording grant, deny, revoke, Accurate Icons cache clear, and fallback
  behavior.
- Explicit primary-click routing enable, disable, missing requirement, and
  revoked permission states.
- Second Bar panel and Compact Strip on built-in display, notch edge cases,
  external display, display disconnect while collapsed, wake, and active Space
  changes.
- Workspaces create, duplicate, archive, switch, Set Builder commit/revert, and
  linked/detached Groups references.
- Installed app launch, URL reuse, no-network probe, local diagnostics export,
  and local alpha zip verification.

## Ship Criteria

- Basic Mode passes release regression with all Pro and Screen Recording
  permissions unavailable.
- v0.2 Stable Second Bar cannot enable or route primary click without explicit
  user action.
- Second Bar setup clearly explains Pro, Accessibility, Accurate Icons, and
  Screen Recording requirements.
- Permission revocation degrades Second Bar to requirements/recovery states
  without breaking Basic Mode.
- Workspaces Stable claims are limited to local app-owned configuration.
- Function Bar, Info Strip, Find Icon, automation, profiles, triggers, and icon
  moving remain Preview, Labs, Experimental, or Deferred as listed above.
- Privacy verification, installed-app verification, local alpha packaging, and
  no-network checks pass.
- Hardware-only gaps are recorded as PASS, FAIL, PARTIAL, BLOCKED, or NOT
  TESTED with exact environment notes.
