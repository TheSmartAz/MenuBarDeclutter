# v0.1.10 Privacy Claims

Current claims:

- Basic Mode does not request Accessibility, Screen Recording, Apple Events, Input Monitoring, or network access.
- Pro Discovery is opt-in and uses local Accessibility metadata only after explicit user setup.
- Accurate Icons is opt-in and can use Screen Recording plus public visible-region ScreenCaptureKit capture for local rendered menu bar thumbnails.
- Workspaces, Function Bar, Set Builder, Info Strip, and Workspace Integration are app-owned local Preview features.
- Diagnostics are privacy-safe and redact protected or user-sensitive references.

Not claimed:

- No cloud sync.
- No telemetry.
- No remote config.
- No private/offscreen menu bar item capture.
- No Developer ID/notarized public distribution status.
