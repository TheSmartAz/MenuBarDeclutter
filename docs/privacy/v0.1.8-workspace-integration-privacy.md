# v0.1.8 Workspace Integration Privacy

Workspace Integration stores local Workspace, Group, and hashed item reference state.

It does not add:

- Screen Recording.
- ScreenCaptureKit.
- Apple Events scripting/control.
- Input Monitoring.
- Network access.
- Telemetry or remote config.
- Private menu bar APIs.

Basic Mode remains fully usable without Pro permissions.
