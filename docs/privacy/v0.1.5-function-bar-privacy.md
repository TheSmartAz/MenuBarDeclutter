# v0.1.5 Function Bar Privacy

Function Bar is an app-owned preview panel. It does not capture pixels, read screen contents, use Screen Recording, use ScreenCaptureKit, use network access, or use private menu bar APIs.

Command items route through existing app commands. Menu bar item proxy references require Pro Discovery metadata and degrade when Pro Mode, Accessibility Discovery, or Accessibility permission is unavailable.

Diagnostics report item counts, availability counts, redacted workspace IDs, placement mode, and display state. Raw workspace item names, protected workspace/group names, raw menu bar identities, live search text, and file paths are not exported by default.
