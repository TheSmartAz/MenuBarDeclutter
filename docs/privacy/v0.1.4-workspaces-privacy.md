# v0.1.4 Workspaces Privacy

Workspaces are local app-owned configuration records. They do not require Accessibility, Screen Recording, ScreenCaptureKit, Apple Events, Input Monitoring, network access, telemetry, or cloud sync.

Basic Mode remains usable without sensitive permissions. Enabling Workspaces Preview must not silently prompt for Accessibility or any other permission.

Workspace diagnostics export counts and redacted IDs only. Protected workspace names, protected group names, workspace item names, raw menu bar item identities, live search text, and file paths are excluded by default.

Workspace switching does not mutate the real menu bar, move icons, click third-party items, or apply physical layout profiles.
