# v0.1.7 Known Limitations

- Info Strip is Preview.
- Calendar and Reminder tiles are not implemented in the current worktree.
- Battery tile may be unavailable depending on local provider support and device state.
- Info Strip is not a Dynamic Island clone, widget dashboard, media controller, notification scraper, or system menu bar replacement.
- Physical workspace switching, automatic profile application, bulk icon moving, and broad third-party activation remain out of scope.
