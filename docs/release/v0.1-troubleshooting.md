# v0.1 Troubleshooting

## Menu Bar Looks Wrong

Use the status menu:

1. Emergency: Reveal All + Reset Separators.
2. Reset Separator Length.
3. Open Settings -> Diagnostics -> Reset Basic Mode.

## Launch at Login Looks Stale

1. Quit all running MenuBarDeclutter copies.
2. Launch `/Applications/MenuBarDeclutter.app`.
3. Open Settings -> General.
4. Click Refresh Login Item Status.
5. If stale entries remain, remove them in System Settings -> General -> Login Items.

## Pro Features Are Unavailable

Enable Pro Mode, grant Accessibility in System Settings, then refresh the AX scan. If permission is revoked, Find Icon and Second Bar should show unavailable states while Basic Mode keeps working.

## Safe Mode

Use Diagnostics -> Safe Mode Next Launch, or launch with the Option key when testing the manual Safe Mode flow. Safe Mode keeps the control item visible and disables risky runtime behaviors.
