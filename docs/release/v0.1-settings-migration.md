# v0.1 Settings Migration

Implemented in `MenuBar-Manager/Core/SettingsMigrationService.swift`.

## Behavior

Fresh installs:

- Stamped with migration version `0.1.1`.
- No update notice is shown.
- No backup is created.

Existing alpha installs:

- Back up current settings to `Application Support/MenuBarDeclutter/backups/`.
- Set migration version to `0.1.1`.
- Show one-time "Updated to v0.1 safe defaults" notice.
- Reset risky flags:
  - Launch at Login cache disabled until revalidated from installed app.
  - Start collapsed and current collapsed state disabled.
  - Auto-rehide, hover reveal, and global hotkey disabled.
  - Pro Mode and Accessibility discovery disabled.
  - Find Icon and Second Bar disabled.
  - Icon Moving disabled and warning suppression cleared.
  - Smart Triggers disabled.
  - Automation paused.
  - Stale Accessibility status cache cleared.
  - Invalid separator lengths repaired.

Profiles are left in place. Corrupted profile JSON is already skipped by `ProfileStore` and surfaced through `lastError`; migration does not delete profile files.

## Tests

`MenuBar-ManagerTests/SettingsMigrationServiceTests.swift` covers:

- Alpha settings migrate to safe defaults.
- Backups include pre-migration values.
- Current migration version does not rewrite settings.
- Fresh installs are stamped without an update notice.
- Older `0.1.0` migration stamps are upgraded to the current migration version without rerunning the full alpha reset path.
