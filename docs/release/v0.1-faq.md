# v0.1 FAQ

## Does Basic Mode need Accessibility?

No. Basic Mode is permission-free.

## Does the app record my screen?

No. v0.1 does not use Screen Recording or ScreenCaptureKit.

## Does the app use the network?

No. v0.1 has no network access, telemetry, or cloud sync.

## Why are Find Icon and Second Bar off by default?

They are Pro Mode features that depend on Accessibility metadata, so they stay off until the user opts in.

## Why is Icon Moving experimental?

It uses simulated Command-drag through public event APIs. Some apps and system items may not move reliably, so it is disabled by default and never runs silently from automation.
