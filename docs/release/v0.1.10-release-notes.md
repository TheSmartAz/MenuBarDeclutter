# MenuBarDeclutter v0.1.10 Release Notes

v0.1.10 is a release-hardening checkpoint for the v0.1.9 source and docs baseline. It does not add a new feature pillar. The goal is to verify the existing internal/local release candidate through build, test, privacy, manual QA, dry-run packaging, and installed-app gates.

## Hardened

- Release identity: `0.1.10` build `11`.
- Current-facing release, support, privacy, design, feature, and manual QA documentation.
- Release dry-run and installed-app verification records.
- Privacy-boundary checks for Basic Mode and Preview surfaces.
- Source/docs searches for future v0.2 overclaims and forbidden capability additions.
- Accurate Icons is documented as a separate opt-in Preview capability for local rendered menu bar thumbnails.

## Feature Status

- Stable surfaces remain the Basic Mode product core: hide/reveal, Launch at Login, privacy-safe diagnostics, recovery/Safe Mode, Guided Manual Arrange, and Pro gated/degraded states.
- Preview surfaces remain Preview: Workspaces, Function Bar, Set Builder, linked Groups, Info Strip, Workspace Integration, Find Icon, Second Bar, Accurate Icons, Placement Planner, New Item Inbox, and Crowded Reveal Rescue.
- Labs and Experimental labels remain unchanged: Menu Bar Spacing Labs stays Labs, and Assisted Move / Icon Moving stays Experimental.

## Privacy

Basic Mode remains permission-free. Accurate Icons is a separate opt-in path that can request Screen Recording for local rendered thumbnails. v0.1.10 does not add Apple Events scripting/control, Input Monitoring, network access, telemetry, cloud sync, remote config, private Apple menu bar APIs, or private/offscreen menu bar capture.
