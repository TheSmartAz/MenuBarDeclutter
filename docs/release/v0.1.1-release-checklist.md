# v0.1.1 Release Checklist

Last updated: 2026-06-29

Status values:

- `PASS`: verified in the Phase 12 progress ledger or by a dated QA result.
- `PARTIAL`: evidence exists, but at least one physical/manual gate remains.
- `BLOCKED`: requires external credentials, hardware, OS state, or an intentional user action outside repository automation.
- `EXPECTED FAIL`: verified to fail safely by design.

Blocking criteria:

- Any ScreenCaptureKit, Screen Recording, Apple Events, Input Monitoring, network entitlement, telemetry, analytics, cloud sync, or remote config addition.
- Any Basic Mode path that requires Pro Mode or Accessibility.
- Any current-facing docs or UI naming this release `v0.2`.
- Any release claim that marks Preview, Labs, or Experimental features as Stable.
- Any import/export path that presents synthetic settings values as real user settings.
