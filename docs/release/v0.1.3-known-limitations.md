# v0.1.3 Known Limitations

## Manual QA Still Required

Physical/session QA remains required before treating all intended stable claims as fully released. The pending areas are tracked in `docs/testing/manual-v0.1.3-system-qa.md` and `docs/testing/manual-v0.1.3-results.md`.

Pending manual areas include Command-drag setup, live collapse/expand/reveal timing, always-hidden reveal, auto-rehide, hover reveal, Launch at Login login-session behavior, Pro permission grant/revoke, crowded/notch displays, external displays, Spaces, sleep/wake, Shortcuts, backup/restore UI, and installed-app behavior.

## Local Runner Instability

The local Xcode hosted UI/app test runner has intermittently timed out before XCTest automation attaches. This is recorded as infrastructure risk when it occurs. Passing pure-logic and successful dry-run release evidence does not replace the blocked hands-on QA.

## Pro Metadata Limits

Find Icon, Second Bar, New Item Inbox, Crowded Rescue metadata, and Placement Planner depend on Pro Discovery when they need Accessibility metadata. They degrade when Pro Mode, Accessibility Discovery, Accessibility permission, or Safe Mode gates are unavailable.

MenuBarDeclutter does not use Screen Recording, ScreenCaptureKit, pixel capture, private menu bar APIs, Apple Events scripting/control, Input Monitoring, or network access.

## Import, Backup, And Migration

Local MenuBarDeclutter backup/restore mechanics are covered by focused automated tests. The broader Import/Export migration assistant remains Preview.

Safe import is merge-by-identity and non-destructive. It does not claim stable competitor migration and does not delete local-only profiles, groups, hotkeys, or spacers.

Safe import skips risky enablement from imported packages, including Icon Moving, Smart Triggers, Menu Bar Spacing Labs, Launch at Login system state, dogfood settings, permission status, and active unlock state.

## Second Bar And Find & Rescue

Second Bar is a metadata/icon browser, not a pixel-perfect duplicate of the real menu bar. Some menu extras may not expose useful Accessibility labels or owning-app metadata.

Crowded and notch rescue use aggregate capacity and policy signals. They do not inspect app menus directly and do not capture menu bar pixels.

## Assisted Move And Icon Moving

Assisted Move actual execution is Experimental. Dry-run and manual guidance are preferred. The app does not claim stable bulk movement or stable broad activation of arbitrary third-party menu extras.

## Distribution

Dry-run release artifacts are not notarized. The current checkpoint is an internal/local alpha artifact, so Developer ID export, notarization, stapling, and notarized Gatekeeper acceptance are deferred. A later public notarized release requires both notarization credentials and an installed Developer ID Application signing certificate.

The main app build is intentionally non-sandboxed for Pro Accessibility Discovery. Basic Mode still avoids sensitive permissions, and release verification still requires hardened runtime metadata, no network entitlements, no ScreenCaptureKit linkage, and no Screen Recording, Apple Events, or Input Monitoring usage strings.
