# v0.1.2 Known Limitations

- Basic Mode uses app-owned status items and separators. It does not use private Apple menu bar APIs, so behavior depends on normal macOS menu bar placement and user Command-drag positioning.
- Guided Manual Arrange is intended stable pending physical QA, but it cannot directly move third-party menu extras in Basic Mode.
- The real Command-drag placement pass and always-hidden visual behavior still require hands-on macOS QA before a complete stable Basic Mode claim.
- Hover reveal has current-session installed-app evidence, and global hotkey delivery has current-session Option-Command-B evidence. Auto-rehide has one scripted URL-driven pass, but the latest direct timed run remained partial; natural timing, postponement, and flicker quality still require hands-on QA.
- Launch at Login uses public login item APIs. Enable/disable registration is verified for the current v0.1.2 candidate, but logout/login or restart behavior remains unverified.
- Safe Mode has scripted one-shot flag, crash-marker, and Option-held launch evidence.
- Pro Accessibility grant/revoke has installed-app evidence with the System Settings grant restored afterward. The local restored scan reported `Discovered 0`, so nonzero third-party Accessibility metadata still needs crowded/live menu QA.
- Pro Discovery depends on Accessibility metadata exposed by macOS and third-party apps. Missing, stale, or unusual Accessibility data can reduce Find Icon, Second Bar, New Items, groups, profiles, and layout accuracy.
- Find Icon reveals/highlights only. It does not broadly activate arbitrary menu bar items.
- Second Bar is a metadata/icon browser. It does not duplicate live menu bar pixels.
- Placement Planner is advisory and non-mutating. It depends on a recent Pro Discovery scan and can only suggest manual placement.
- New Item Inbox has privacy-safe detection, dismissal, reset, persistence, and status-menu review count plumbing. Richer per-item placement actions remain deferred.
- Crowded Reveal Rescue uses local capacity estimates and can choose inline reveal, Second Bar, Full Menu Bar Mode, or a layout suggestion. It may still need manual layout adjustment on notch or external-display setups.
- Icon Moving is Experimental, explicit user action only, and can fail on system items or third-party items that resist Command-drag movement.
- Smart Triggers, Dynamic Hotkeys, Private Access, group status items, App Intents automation, URL automation, and import/export migration are Preview surfaces.
- Menu Bar Spacing is Labs and must not automatically mutate global spacing defaults or restart system processes.
- Settings packages intentionally omit volatile or private local state such as permission status, authentication status, dogfood run IDs, backup/apply state, and the deprecated primary separator setting.
- Safe import leaves Launch at Login/Login Items system state unchanged and does not enable Icon Moving, Smart Triggers, or Menu Bar Spacing Labs from an imported package.
- Developer ID notarization requires external Apple credentials that are not stored in this repository.
- Xcode hosted Swift test runs can fail before attachment on this menu bar app in local automation. Build, privacy-boundary, dry-run release, and manual QA evidence remain required gates.
