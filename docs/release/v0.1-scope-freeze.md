# v0.1 Scope Freeze

## Product Promise

MenuBarDeclutter v0.1.0 is a privacy-first macOS 26+ menu bar utility focused on permission-free Basic Mode.

Included:

- Permission-free Basic Mode for hiding/revealing menu bar items through separator-based layout.
- Optional always-hidden zone.
- Optional auto-rehide, hover reveal, and hotkey.
- Settings, onboarding, diagnostics, and privacy-safe export.
- Launch at Login after installed-app QA passes.
- Health and Safe Mode recovery.
- Optional Pro Mode:
  - Accessibility discovery.
  - Find Icon.
  - Second Bar.
- Experimental/Labs:
  - Icon Moving.
  - Smart Triggers.
  - Advanced profile zone behavior.

Excluded:

- Phase 10 visual icon capture.
- ScreenCaptureKit.
- Screen Recording.
- Apple Events permission.
- Input Monitoring.
- Network, telemetry, cloud sync.
- AppleScript dictionary unless implemented later with a separate privacy review.

Anything outside this scope is tracked in `docs/roadmap/post-v0.1.md`.
