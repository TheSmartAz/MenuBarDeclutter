# v0.1 Privacy

MenuBarDeclutter v0.1.0 is local-first.

## Not Used

- No Screen Recording.
- No ScreenCaptureKit.
- No Apple Events permission.
- No Input Monitoring.
- No network access.
- No telemetry.
- No cloud sync.
- No private APIs.

## Basic Mode

Basic Mode requires no Accessibility permission and no sensitive macOS privacy permission. It uses public `NSStatusItem` behavior and separator-based layout.

## Pro Mode

Pro Mode is optional. It requests Accessibility only after explicit opt-in. If Accessibility is missing, denied, revoked, or unavailable, Pro surfaces degrade and Basic Mode remains usable.

## Diagnostics

Diagnostics exports are privacy-safe. They exclude screenshots, screen contents, live search text, selected item identity, personal file paths by default, and network data.

Verification scripts:

```sh
scripts/verify_privacy_boundary.sh
scripts/verify_privacy_boundary.sh build/Export/MenuBarDeclutter.app
scripts/verify_installed_app.sh /Applications/MenuBarDeclutter.app
```
