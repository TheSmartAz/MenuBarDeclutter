# v0.1 Privacy

MenuBarDeclutter v0.1 is local-first. The current active line is `v0.1.10`.

## Not Used

- No Apple Events permission.
- No Input Monitoring.
- No network access.
- No telemetry.
- No cloud sync.
- No private APIs.

## Basic Mode

Basic Mode requires no Accessibility permission and no sensitive macOS privacy permission. It uses public `NSStatusItem` behavior and separator-based layout.

## Pro Mode

Pro Mode is optional. It requests Accessibility only after explicit opt-in. If Accessibility is missing, denied, revoked, or unavailable, Pro surfaces degrade and Basic Mode remains usable.

## Accurate Icons

Accurate Icons is separate from Basic Mode and off by default. When the user explicitly enables it and requests permission, it can use Screen Recording plus public ScreenCaptureKit visible-region capture for local rendered menu bar thumbnails. If permission is missing or revoked, surfaces fall back to stale thumbnails or app icons.

## Diagnostics

Diagnostics exports are privacy-safe. They exclude screenshots, screen contents, rendered icon thumbnails, live search text, selected item identity, personal file paths by default, and network data.

Verification scripts:

```sh
scripts/verify_privacy_boundary.sh
scripts/verify_privacy_boundary.sh build/Export/MenuBarDeclutter.app
scripts/verify_installed_app.sh /Applications/MenuBarDeclutter.app
```
