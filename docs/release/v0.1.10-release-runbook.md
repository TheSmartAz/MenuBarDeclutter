# v0.1.10 Release Runbook

Use `docs/testing/qa-process.md` before this file to confirm the change is in
the Release Candidate lane. Developer ID export, notarization, stapling, and
public distribution are not part of the current scope.

1. Confirm `Config/Shared.xcconfig` reports `MARKETING_VERSION = 0.1.10` and `CURRENT_PROJECT_VERSION = 11`.
2. Run `xcodebuild -scheme MenuBarDeclutter -destination 'platform=macOS' build CODE_SIGN_IDENTITY=- CODE_SIGNING_REQUIRED=NO`.
3. Run `xcodebuild test -scheme MenuBarDeclutter -destination 'platform=macOS' -only-testing:MenuBarDeclutterTests -enableCodeCoverage NO`.
4. Run `scripts/verify_privacy_boundary.sh`.
5. Run source/docs searches for v0.2 overclaims and forbidden capability additions.
6. Use `scripts/build_release.sh` or `scripts/build_release.sh --dry-run` for local alpha packaging; dry-run is the default.
7. Use `scripts/build_release.sh --dry-run --install --verify-installed` for installed-app verification.
8. Run UI tests only as an explicit lane, for example `scripts/test.sh --ui` or the split UI lane in `scripts/qa_preflight.sh`, and record any local runner instability separately from unit-test results.
9. Record manual QA results in `docs/testing/manual-v0.1.10-results.md`.
