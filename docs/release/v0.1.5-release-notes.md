# v0.1.5 Release Notes

v0.1.5 adds the Function Bar Preview and Set Switcher on top of Workspaces Foundation.

Included:

- App-owned Function Bar panel.
- Function Bar item resolution for commands, groups, menu bar proxies, spacers, dividers, and deferred Info Strip placeholders.
- Set Switcher for active Workspace changes.
- Command Center routing for Function Bar show/hide/toggle.
- Status menu and Advanced Workspaces Preview controls.

Not included: stable system menu bar replacement, live icon cloning, physical workspace switching, Info Strip runtime, full drag/drop builder, Screen Recording, ScreenCaptureKit, network widgets, telemetry, or private APIs.
