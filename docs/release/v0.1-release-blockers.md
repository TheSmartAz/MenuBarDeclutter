# v0.1 Release Blockers

## Must Fix Before v0.1

- Any S0 privacy breach, data loss, app-trapping, or unrecoverable menu bar state.
- Any confirmed S1 Basic Mode failure.
- Privacy verification script failure.
- Safe Mode rescue failure.
- Installed-app launch failure.
- Launch at Login failure if advertised as supported.

## Acceptable Known Limitations

- Icon Moving issues while disabled by default and recoverable.
- Pro Mode AX metadata gaps that do not break Basic Mode.
- Second Bar pixel fidelity limitation.
- Notch/external display limitations when documented and recoverable.
- Missing real notarization for internal dry-run builds when clearly documented.

## Current Status

No confirmed automated Basic Mode blocker is known in the latest recorded Phase 9.5 validation. That recorded run passed automated preflight, dogfood preflight, release artifact verification, installed-app verification, and privacy verification.

Public v0.1 distribution is blocked by missing Developer ID Application identity/notarization credentials. Manual gates remain open for Launch at Login restart/login behavior, Safe Mode option/crash recovery, real menu bar behavior, Accessibility grant/revoke, external display/notch/sleep-wake/Spaces, and interactive network observation.
