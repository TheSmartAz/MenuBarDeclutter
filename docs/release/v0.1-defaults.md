# v0.1 Defaults

Fresh installs and Reset All Settings use these defaults.

| Setting | v0.1 Default | Reason |
| --- | --- | --- |
| Basic Mode | Enabled | Core product promise |
| Pro Mode | Disabled | Explicit opt-in only |
| Accessibility Discovery | Disabled | Requires Pro opt-in |
| Find Icon | Disabled | Requires Pro requirements |
| Second Bar | Disabled | Requires Pro requirements |
| Icon Moving | Disabled | Experimental |
| Smart Triggers | Disabled | Conservative release freeze |
| Automation Paused | Enabled | No surprise automation |
| Auto-rehide | Disabled | Optional, not fully dogfooded |
| Hover reveal | Disabled | Optional, not fully dogfooded |
| Global hotkey | Disabled | Avoid conflicts by default |
| Always-hidden | Disabled | User must choose layout |
| Start collapsed | Disabled | First launch starts expanded |
| Safe Mode | Available | Recovery surface |

## Code Alignment

`SettingsStore` registered defaults now match this table:

- `searchEnabled = false`
- `autoRehideEnabled = false`
- `automationPaused = true`
- Pro, Second Bar, Icon Moving, Smart Triggers, Hover Reveal, Hotkey, Always-hidden, and Start Collapsed remain disabled.

## Migration

Older alpha settings migrate through `SettingsMigrationService`. Risky alpha flags are reset to this safe default set and backed up to Application Support Backups.
