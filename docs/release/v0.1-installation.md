# v0.1 Installation

Current active line: `v0.1.10`.

1. Unzip the current dry-run package, usually `MenuBarDeclutter-v0.1.10-alpha.zip`.
2. Move `MenuBarDeclutter.app` to `/Applications`.
3. Launch `/Applications/MenuBarDeclutter.app`.
4. Confirm there is no Dock icon and the menu bar item appears.
5. Open Settings from the status menu.
6. Validate Launch at Login only from the installed app.

For local development artifacts:

```sh
scripts/build_release.sh --dry-run --install --verify-installed
scripts/qa_installed_app_smoke.sh --app-path /Applications/MenuBarDeclutter.app
```

Developer ID signing, notarization, stapling, and public distribution are out of scope until explicitly requested.
