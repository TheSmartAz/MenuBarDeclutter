# MenuBarDeclutter v0.1.0 Release Notes

MenuBarDeclutter v0.1.0 is the Basic Stable freeze for a privacy-first macOS 26+ menu bar decluttering utility.

## Included

- Permission-free Basic Mode collapse, expand, reveal all, and separator reset.
- Settings, onboarding, diagnostics, and privacy-safe exports.
- Health checks and Safe Mode recovery.
- Optional Launch at Login after installed-app validation.
- Optional Pro Mode with Accessibility-only discovery after explicit opt-in.
- Optional Find Icon and Second Bar when Pro requirements are met.
- Experimental Icon Moving in Labs, disabled by default.

## Privacy

No ScreenCaptureKit, Screen Recording, Apple Events permission, Input Monitoring, network access, telemetry, cloud sync, or private APIs.

## Known Limitations

See `docs/release/v0.1-known-limitations.md`.

## Release Status

Developer ID notarization is blocked until credentials are configured. Dry-run notarization and local installed-app validation scripts are available.
