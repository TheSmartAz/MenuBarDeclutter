# v0.1 Known Limitations

1. Phase 10 visual icon capture is not implemented.
2. Second Bar uses app/bundle icons and Accessibility metadata, not captured menu bar pixels.
3. Some menu bar items may not expose complete Accessibility metadata.
4. Some menu bar items may not be movable.
5. Icon Moving is experimental and disabled by default.
6. Profiles do not silently run bulk icon moves.
7. Smart Triggers are conservative and disabled by default.
8. Focus/Wi-Fi providers remain inactive.
9. Notch/external display behavior depends on real layout and may need manual adjustment.
10. Basic Mode uses separator-based hiding, not private Apple menu bar APIs.
11. Launch at Login must be validated from `/Applications`, not Xcode or DerivedData.
12. Notarization requires Developer ID credentials that were not present during the local audit.
