# MenuBarDeclutter v0.1.3 Release Notes

MenuBarDeclutter `v0.1.3` is a competitive core catch-up release.

The release story is:

> MenuBarDeclutter is a privacy-first menu bar declutter tool. Hide clutter without sensitive permissions, arrange icons safely, find hidden items when needed, and recover if layout breaks.

## Current Scope

- Active app version is `0.1.3` with build `4`.
- Release tooling produces `MenuBarDeclutter-v0.1.3.zip` plus the local dry-run alpha artifact when alpha packaging is enabled.
- Find & Rescue work focuses on speed, ranking quality, keyboard action routing, and privacy-safe diagnostics.
- Second Bar recovery, Crowded Rescue, Guided Arrange, Placement Planner preferences, and Assisted Move dry-run/dogfood guardrails have landed as v0.1.3 workstreams.
- New Item Inbox polish and basic Shortcuts validation have landed as v0.1.3 workstreams.
- Local MenuBarDeclutter backup/restore hardening has landed with schema metadata, dry-run no-mutation behavior, backup-before-apply, selected-section service support, rollback on apply failure, and risky-feature guardrails.
- Release rehearsal has passing dry-run and installed-app dry-run evidence for the current internal/local alpha artifact. Developer ID export/notarization is deferred for public distribution and remains unavailable on this machine because no Developer ID Application signing certificate is installed.

## Privacy Boundary

Basic Mode remains permission-free. v0.1.3 does not add Screen Recording, ScreenCaptureKit, Apple Events scripting/control, Input Monitoring, network access, telemetry, analytics, cloud sync, remote config, or private menu bar APIs.

Pro Discovery remains opt-in and must degrade gracefully when permissions are missing, denied, revoked, or unavailable.

## Release Status

Current validation state is recorded in `docs/progress/phase-16-v0.1.3-competitive-core-catch-up.md`.

## Boundaries

Find Icon, Second Bar, Placement Planner, New Item Inbox, Crowded Rescue, Shortcuts, and the broader Import/Export migration assistant should be described as Preview unless a narrower support doc marks a local mechanic as stable or near-stable.

Assisted Move actual execution and icon moving beyond manual Command-drag remain Experimental.

Do not claim stable bulk icon moving, stable competitor migration, Screen Recording-free pixel duplication, ScreenCaptureKit capture, cloud sync, telemetry, or future-release availability.
