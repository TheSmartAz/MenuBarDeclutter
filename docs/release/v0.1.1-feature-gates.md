# v0.1.1 Feature Gates

The Settings UI uses the same status vocabulary as this document:

| Status | Meaning |
| --- | --- |
| Stable | Supported in the `v0.1.1` release scope when its documented requirements are met. |
| Preview | Available for local testing, but conservative gates and fail-closed behavior remain part of the contract. |
| Labs | Requires explicit opt-in and must never automatically mutate system-level state without user action. |
| Experimental | Requires explicit enablement or confirmation and may fail depending on macOS state. |
| Disabled | Turned off in app settings. |
| Unavailable | Requirements are missing, denied, or not attached. |
| Deferred | Documented for later work and not part of this release. |

## Stable

| Feature | Gate | Expected Failure Mode |
| --- | --- | --- |
| Basic expand/collapse/reveal-all | None beyond app launch | Visible status item remains available. |
| Auto-rehide | User setting | No countdown when disabled. |
| Hover reveal | User setting | No hover polling when disabled. |
| Always-hidden zone | User setting and separator | Falls back to primary hidden zone behavior. |
| Global visibility hotkey | User setting and valid binding | Status menu remains usable. |
| Launch at Login | Explicit user setting | App can still launch manually. |
| Diagnostics export | Explicit user action | Export reports local error; no upload. |
| Safe Mode and recovery | Local flags/crash marker | Starts expanded with optional services suppressed. |
| Pro Accessibility Discovery gating | Pro Mode, discovery toggle, macOS permission | Shows unavailable/degraded state without prompting automatically. |
| Find Icon reveal/highlight | Pro gates plus search enabled | Disabled or permission-needed panel. |
| Second Bar browsing | Pro gates plus Second Bar enabled | Requirements panel. |
| Profiles basic dry-run/apply | Profiles enabled and conservative settings only | Dry-run or blocked result. |

## Preview

Smart Triggers, Dynamic Hotkeys, Private Access, group status items, App Intents automation, import/export migration assistant, and crowded reveal rescue automation are Preview in `v0.1.1`. They must be off, paused, dry-run, or visibly blocked when their gate is missing.

Manual groups can remain local and permission-free, but optional group status items are Preview.

Import/Export Preview writes a real local JSON settings package with `packageVersion`, `appVersion`, `exportKind`, `createdAt`, `redactionMode`, and `omittedSettings` metadata. Exported setting values must be current local values rather than synthetic marker text. Import dry-runs first, creates a backup, then safe-applies supported settings and package objects by ID. Safe apply must skip conflicting dynamic hotkeys and must not enable Icon Moving, Smart Triggers, or Menu Bar Spacing Labs from an imported package.

Settings packages intentionally omit volatile or private state, including permission status, Private Access authentication status, dogfood run IDs, backup/apply state, and the deprecated primary separator setting.

## Labs

Menu Bar Spacing Labs is Labs. It must require explicit enablement and must not automatically mutate global menu bar spacing defaults.

## Experimental

Icon Moving is Experimental. It requires explicit user action, Pro Mode, Accessibility permission, icon-moving enablement, safety checks, and first-use confirmation unless the user has explicitly suppressed that confirmation.

## Deferred

ScreenCaptureKit visual capture, Screen Recording, Apple Events scripting, Input Monitoring, network/cloud sync, telemetry, and broad import-from-competitor promises are Deferred.
