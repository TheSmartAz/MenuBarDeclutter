# v0.1.1 Pro Workflow Notes

`v0.1.1` remains a privacy-first release line. Basic Mode is still the default and works without Accessibility, Screen Recording, ScreenCaptureKit, Apple Events, Input Monitoring, network access, telemetry, cloud sync, or private menu bar APIs.

## Current Pro Workflows

- Command Center provides shared routing and gate results for many advanced actions.
- Find Icon and Second Bar use local Accessibility metadata only after explicit Pro/Discovery/permission opt-in.
- Crowded Rescue, Groups, Private Access, Profiles, Dynamic Hotkeys, App Intents, URL automation, and Import/Export are Preview unless called Stable in a specific feature doc.
- Icon Moving remains Experimental.
- Spacing Labs remains Labs; apply/restore/reset are deferred in `v0.1.1`.

## Boundaries

- Private Access protects app-owned MenuBarDeclutter actions only. It is not encryption and does not hide third-party icons that are already visible in the system menu bar.
- App Intents and URL automation must respect Safe Mode, automation pause, Pro, Accessibility, Labs, and Private Access gates.
- Diagnostics and exports must exclude live search text, selected item identities, protected names, protected targets, screenshots, screen contents, and full paths unless a user explicitly chooses an export flow that includes them.

## Remaining Manual QA

Manual QA is still required for live crowded menu bars, notch/external display behavior, sleep/wake, Launch at Login, Touch ID/password outcomes, real Shortcuts execution, URL automation from external apps, and Experimental Icon Moving.
