# v0.1 Copy Review

Terms to use consistently:

- Basic Mode
- Pro Mode
- Find Icon
- Second Bar
- Icon Moving
- Automation
- Safe Mode

## Updated In This Pass

- Launch at Login copy now warns when running outside `/Applications`.
- Diagnostics shows the current bundle path and `/Applications` status.
- The status menu includes an emergency recovery action: Reveal All + Reset Separators.
- v0.1 docs clarify that Icon Moving is experimental and disabled by default.
- v0.1 docs avoid implying perfect control over all third-party menu bar icons.
- Privacy docs explicitly exclude ScreenCaptureKit, Screen Recording, Apple Events, Input Monitoring, network, telemetry, and cloud sync.

## Copy Rules

- Do not imply the app can perfectly control all third-party menu bar icons.
- Do not imply Icon Moving always works.
- Do not imply Screen Recording or visual capture exists.
- Pro Mode copy must say Accessibility is requested only after explicit opt-in.
- Diagnostics export copy must say exports are privacy-safe and exclude screen contents.
