# v0.1.1 Release Runbook

Run from the repository root.

1. Clean release outputs:
   ```sh
   scripts/release_clean.sh
   ```
2. Confirm schemes:
   ```sh
   xcodebuild -list -project MenuBar-Manager.xcodeproj
   ```
3. Run tests and trust checks:
   ```sh
   xcodebuild test -scheme MenuBarDeclutter -destination 'platform=macOS'
   scripts/qa_preflight.sh
   scripts/verify_privacy_boundary.sh
   scripts/qa_dogfood_preflight.sh
   ```
4. Build a local dry-run release:
   ```sh
   scripts/build_release.sh --dry-run
   ```
5. Install and verify the dry-run artifact:
   ```sh
   scripts/build_release.sh --dry-run --install --verify-installed
   ```
6. Run manual QA and dogfood evidence:
   ```text
   docs/testing/manual-v0.1.1-system-qa.md
   docs/testing/manual-v0.1.1-results-template.md
   docs/testing/manual-v0.1.1-dogfood-script.md
   docs/testing/manual-v0.1.1-known-acceptable-risks.md
   ```
7. For Developer ID distribution, configure notarization credentials outside the repo, then run:
   ```sh
   scripts/build_release.sh --version 0.1.1 --notarize --staple
   ```
8. Validate the notarized app:
   ```sh
   scripts/verify_release_artifact.sh build/Export/MenuBarDeclutter.app --expected-version 0.1.1 --expected-build 2 --require-notarized
   scripts/release_validate_gatekeeper.sh build/Export/MenuBarDeclutter.app
   ```
9. Package names must be:
   ```text
   build/Dist/MenuBarDeclutter-v0.1.1.zip
   build/Dist/MenuBarDeclutter-v0.1.1-alpha.zip
   ```

Do not rename this release `v0.2`.
