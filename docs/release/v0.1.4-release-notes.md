# v0.1.4 Release Notes

v0.1.4 introduces Workspaces Foundation as a Preview system.

Included:

- Local Workspace model and JSON store.
- Safe defaults: Default, Focus, and Meeting.
- Active workspace switching and persistence.
- Group/profile reference groundwork.
- Privacy-safe diagnostics.
- Advanced Workspaces Preview entry.

Not included: Function Bar runtime, Info Strip runtime, Set Builder drag/drop, physical workspace switching, bulk icon moving, Screen Recording, ScreenCaptureKit, network access, telemetry, or private APIs.
