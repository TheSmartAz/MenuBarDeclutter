# v0.1.10 Known Limitations

- Workspaces and Workspace Integration are Preview, not Stable.
- Workspaces configure MenuBarDeclutter-owned Function Bar and Info Strip surfaces. They do not replace or control the macOS system menu bar.
- Workspace item assignment stores local references only; it does not move real menu bar icons.
- Pro Discovery dependent views still require explicit Pro Mode, Accessibility Discovery, and macOS Accessibility permission.
- Accurate Icons only captures visibly rendered menu bar item pixels with public APIs. Offscreen, overflow, notch-hidden, or non-rendered items can use stale thumbnails or app-icon fallbacks.
- Hardware-only checks may remain BLOCKED if this local session cannot access a physical notch/external display setup, the NSStatusItem menu, or hands-on permission prompts.
- Developer ID distribution, notarization, and stapling are out of scope until explicitly requested.
