# v0.1.1 Local Dry Run

Use this path when Developer ID or notarization credentials are unavailable.

```sh
scripts/release_clean.sh
scripts/build_release.sh --dry-run
```

Expected outputs:

```text
build/Archives/MenuBarDeclutter.xcarchive
build/Export/MenuBarDeclutter.app
build/Dist/MenuBarDeclutter-v0.1.1-alpha.zip
build/Dist/MenuBarDeclutter-v0.1.1.zip
```

Dry-run behavior:

- Copies the archived app directly instead of using Developer ID export.
- Does not submit notarization.
- Does not staple.
- Runs release artifact verification.
- Leaves Gatekeeper notarization warnings as warnings unless `--require-notarized` is used.

Installed dry-run check:

```sh
scripts/build_release.sh --dry-run --install --verify-installed
```

This installs the local build and verifies bundle ID, version/build, app category, `LSUIElement`, URL scheme, sensitive usage strings, sandbox, hardened runtime, network entitlements, ScreenCaptureKit linkage, code signature, and expected non-notarized Gatekeeper/stapler warnings.
