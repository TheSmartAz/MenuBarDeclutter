# v0.1.1 Public Claims

MenuBarDeclutter `v0.1.1` may claim:

- Native macOS 26.0+ app.
- Privacy-first, local-first menu bar decluttering.
- Basic Mode does not request Accessibility, Screen Recording, Apple Events, Input Monitoring, network access, telemetry, cloud sync, or ScreenCaptureKit.
- Pro Mode is opt-in and uses Accessibility metadata only after explicit user enablement and explicit macOS permission grant.
- Find Icon can search Accessibility snapshots and reveal/highlight approximate item locations when Pro gates are satisfied.
- Second Bar can browse hidden-item metadata and app icons when Pro gates are satisfied.
- Diagnostics exports are local and privacy-safe by default.
- Import/Export Preview can write a local, schema-versioned MenuBarDeclutter settings package and dry-run a selected package before any future apply path.
- Safe Mode and recovery are permission-free.

MenuBarDeclutter `v0.1.1` must not claim:

- Stable icon moving.
- Stable menu bar spacing mutation.
- Stable import/export migration or competitor migration.
- Import apply/commit support.
- Stable Smart Triggers or App Intents automation.
- Broad activation of arbitrary third-party menu bar items.
- Hiding of third-party icons already visible in the system menu bar through Private Access.
- Screen Recording, ScreenCaptureKit, Apple Events, Input Monitoring, cloud sync, remote config, telemetry, or analytics.
