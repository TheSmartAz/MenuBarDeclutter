# v0.1 Uninstall

To remove only the app:

```sh
scripts/release_uninstall_local.sh --yes
```

To remove the app and explicitly purge MenuBarDeclutter user data:

```sh
scripts/release_uninstall_local.sh --yes --purge-user-data
```

The purge path is opt-in and prints the affected paths before deletion:

- `~/Library/Application Support/MenuBarDeclutter`
- `~/Library/Preferences/Yongjun-Zhang.MenuBarDeclutter.plist`
- `~/Library/Caches/Yongjun-Zhang.MenuBarDeclutter`
