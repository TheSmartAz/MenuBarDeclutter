# v0.1.1 Known Limitations

- Basic Mode uses app-owned status items and separators. It does not use private Apple menu bar APIs, so behavior depends on normal macOS menu bar placement and user command-drag positioning.
- Pro discovery depends on Accessibility metadata exposed by macOS and third-party apps. Missing, stale, or unusual Accessibility data can reduce Find Icon, Second Bar, groups, profiles, and layout accuracy.
- Find Icon reveals/highlights only. It does not broadly activate arbitrary menu bar items.
- Second Bar is a metadata/icon browser. It does not duplicate live menu bar pixels.
- Icon Moving is Experimental, explicit user action only, and can fail on system items or third-party items that resist command-drag movement.
- Smart Triggers, Dynamic Hotkeys, Private Access, group status items, App Intents automation, and import/export migration are Preview surfaces.
- Import/Export Preview writes a real local JSON settings package, has a safe apply path after dry-run plus backup, and can restore the latest local backup. Apply and restore are merge-by-ID rather than destructive full restores.
- Settings packages intentionally omit volatile or private local state such as permission status, authentication status, dogfood run IDs, backup/apply state, and the deprecated primary separator setting.
- Safe import leaves Launch at Login/Login Items system state unchanged and does not enable Icon Moving, Smart Triggers, or Menu Bar Spacing Labs from an imported package.
- Menu Bar Spacing is Labs and must not automatically mutate global spacing defaults or restart system processes.
- Developer ID notarization requires external Apple credentials that are not stored in this repository.
- A 2026-06-29 baseline UI visibility failure in `scripts/qa_preflight.sh` was rechecked on 2026-06-30; the focused Search UI test, full `xcodebuild test`, and full `scripts/qa_preflight.sh` pass in the current tree.
