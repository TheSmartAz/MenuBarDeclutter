# v0.1.10 Feature Status Audit

> **Forward-looking note (2026-07-07):** A feature-rationalization decision record —
> [`docs/roadmap/feature-rationalization-2026-07-07.md`](../roadmap/feature-rationalization-2026-07-07.md)
> — sets a new product direction (Accessibility-driven real icon control, Workspaces
> as the wedge) that will change several statuses below in future release lines. This
> document still describes the **v0.1.10 release as shipped** and is left unchanged as
> a historical record.

v0.1.10 does not promote any Preview, Labs, Experimental, or Deferred surface to Stable. It verifies the existing v0.1.9 boundaries for an internal/local release candidate.

## Stable

- Basic expand, collapse, toggle, reveal all, and always-hidden reveal.
- Launch at Login opt-in.
- Privacy-safe diagnostics and local recovery.
- Guided Manual Arrange with normal macOS Command-drag.

## Preview

- Workspaces.
- Workspace Integration.
- Function Bar.
- Set Builder.
- Linked/detached Groups in Workspaces.
- Info Strip.
- Find Icon and Second Bar.
- Accurate Icons rendered thumbnail capture.
- Placement Planner and New Item Inbox.
- Crowded Reveal Rescue.
- Profiles, Smart Triggers, Dynamic Hotkeys, Private Access, App Intents, URL automation, and broader import/export.

## Labs

- Menu Bar Spacing Labs.

## Experimental

- Assisted Move / Icon Moving.

## Deferred

- Private/offscreen menu bar item capture.
- Apple Events scripting/control.
- Input Monitoring.
- Network/cloud sync, telemetry, analytics, crash upload, and remote config.
- Stable automated physical menu bar item moving.
