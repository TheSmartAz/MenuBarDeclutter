# v0.1.6 Release Notes

v0.1.6 adds Set Builder Preview and Linked Groups.

Included:

- Workspace draft editor.
- Create, rename, duplicate, archive, switch, commit, and revert.
- Command, spacer, divider, group, detached group, and Pro-gated proxy insertion.
- Linked/detached Group reference model.
- Function Bar refresh after committed Workspace changes.
- Workspace snapshot support in local import/export.

Not included: stable Set Builder claims, physical workspace switching, bulk icon moving, Info Strip runtime, Screen Recording, ScreenCaptureKit, network widgets, telemetry, or private APIs.
