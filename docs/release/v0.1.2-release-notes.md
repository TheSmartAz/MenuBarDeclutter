# MenuBarDeclutter v0.1.2 Release Notes

MenuBarDeclutter `v0.1.2` is a polish and manual-QA release. It is not `v0.2`.

The release story is:

> Hide clutter without sensitive permissions. Arrange icons safely. Find hidden items when needed. Recover if layout breaks.

## What Changed

- Active app version is `0.1.2` with build `3`.
- Release tooling now derives the default build number from project config and produces `MenuBarDeclutter-v0.1.2.zip` plus the local alpha artifact when dry-run alpha packaging is enabled.
- Settings keeps the seven-section product shape: General, Hide & Reveal, Arrange, Find & Rescue, Privacy, Recovery, Advanced.
- Guided Arrange uses clearer step titles, first-class status-menu routing, and recovery-oriented help.
- Find & Rescue has direct actions for Find Icon and Second Bar, a clearer New Items story, and a simpler crowded-rescue preference set.
- The status menu is shorter for daily use and moves relevant power-user actions under Advanced.
- Recovery now includes a visible "I can't find my icons" path with Expand, Reveal All, Reset Layout, status item recreation, temporary auto-rehide/hover-disable actions, Safe Mode, diagnostics, and a support-guide link.
- Pro setup copy remains explicit: no automatic Accessibility prompt, no pixels, no Screen Recording, no ScreenCaptureKit, and no telemetry.

## Intended Stable Core Pending Physical QA

- Basic expand, collapse, reveal all, always-hidden reveal, auto-rehide, hover reveal, global hotkey, Launch at Login, diagnostics export, Safe Mode, and reset layout.
- Guided Manual Arrange with normal macOS Command-drag.
- Privacy-safe diagnostics export.

These are the intended stable product surfaces for `v0.1.2`; release completion remains blocked until the physical/manual QA rows in `docs/testing/manual-v0.1.2-results.md` are resolved or explicitly deferred.

## Privacy

MenuBarDeclutter does not use Screen Recording, ScreenCaptureKit, Apple Events permission, Apple Events scripting/control of other apps, Input Monitoring, network telemetry, analytics, crash upload, cloud sync, remote config, or private menu bar APIs. The local `menubardeclutter://` handler only receives commands addressed to this app.

Basic Mode remains usable when Pro Mode is off, Accessibility Discovery is off, Accessibility permission is denied or revoked, and all Preview/Labs/Experimental features are disabled.
