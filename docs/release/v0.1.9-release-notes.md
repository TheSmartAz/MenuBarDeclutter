# MenuBarDeclutter v0.1.9 Release Notes

v0.1.9 is the Workspace MVP Design RC. It promotes Workspaces to a top-level Preview section and finalizes the local-only Workspace Integration surface for this release line.

## Added

- Top-level Workspaces Settings route.
- Workspace Integration dashboard in Workspaces settings.
- Workspace-aware Find Icon filters and result badges.
- New Item assignment logic for Workspaces and Groups.
- Crowded rescue fallback preference that can use Function Bar when enabled.
- Physical profile binding preview planner with no automatic physical item movement.
- v0.1.9 release, feature, privacy, design, and manual QA documentation.

## Still Preview

- Workspaces, Function Bar, Set Builder, linked Groups, Info Strip, Workspace Integration, Find Icon, Second Bar, Placement Planner, New Item Inbox, and Crowded Reveal Rescue.

## Privacy

Basic Mode remains the stable permission-free product core. v0.1.9 does not add Screen Recording, ScreenCaptureKit, Apple Events scripting/control, Input Monitoring, network access, telemetry, cloud sync, remote config, or private Apple menu bar APIs.
