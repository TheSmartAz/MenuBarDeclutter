# Info Strip Support

Info Strip is app-owned Preview UI for lightweight Workspace context. It is available when Workspaces Preview and Info Strip Preview are enabled, and when the active Workspace enables Info Strip.

Use Info Strip for local status tiles configured from Set Builder. Tile providers must stay local and privacy-preserving in `v0.1.9`.

Info Strip does not replace the macOS menu bar, use Screen Recording, use ScreenCaptureKit, scrape notifications, use network widgets, or capture screen contents. If Safe Mode is active or Preview gates are off, Info Strip stays unavailable while Basic Mode continues to work.
