# Function Bar Support

Function Bar is app-owned Preview UI for the active Workspace. It is available when Workspaces Preview and Function Bar Preview are enabled.

Use Function Bar to inspect or trigger Workspace items that MenuBarDeclutter owns, including safe commands, dividers, spacers, linked Groups, detached Groups, and menu bar item references when Pro metadata is available.

Function Bar does not replace the macOS menu bar, capture pixels, use Screen Recording, use ScreenCaptureKit, or move third-party menu bar icons. If Safe Mode is active, Function Bar stays unavailable and Basic Mode controls remain reachable.

Crowded Reveal Rescue can prefer Function Bar as a fallback when the global crowded-rescue fallback setting allows it. If Function Bar is unavailable, the decision engine falls back to the configured safe alternative.
