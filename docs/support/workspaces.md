# Workspaces Support

Workspaces is the top-level Preview settings page for app-owned Workspace configuration in `v0.1.9`.

Use Workspaces to:

- Create, duplicate, archive, and switch local Workspace records.
- Enable or disable Workspaces Preview, Function Bar Preview, Set Builder Preview, and Info Strip Preview.
- Review active Workspace status, item counts, linked Groups, unassigned items, and profile binding status.
- Open Function Bar, Info Strip, Set Builder, and New Items review actions.
- Inspect Workspace Integration diagnostics for local usage indexing and missing references.

Workspaces does not replace or control the macOS system menu bar. Physical profile binding remains preview-only planning copy; it must not move real menu bar icons or apply layout mutations.

Basic Mode remains usable when Workspaces Preview is off, Safe Mode is active, or Pro metadata is unavailable.
