# Info Strip Support

Open the top-level Workspaces settings page, then enable Info Strip Preview.

To see Info Strip:

- Enable Workspaces Preview.
- Enable Function Bar Preview if testing idle/hover behavior.
- Enable Info Strip Preview.
- Enable Info Strip for the active Workspace.
- Choose local tile providers in Set Builder.
- Open Info Strip from Settings or the status menu.

Info Strip is app-owned Preview UI. It does not replace the macOS menu bar, use Screen Recording, use ScreenCaptureKit, use network widgets, or scrape notifications.

Current v0.1.10 scope keeps Info Strip in Preview. External multi-display placement checks remain manual QA follow-up.
