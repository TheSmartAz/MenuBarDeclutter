# Set Builder Support

Set Builder is available from Advanced, Workspaces Preview.

Use it to edit app-owned Workspace and Function Bar items:

- Add safe commands.
- Add spacers and dividers.
- Add linked or detached Groups.
- Add menu bar item proxy references when Pro Discovery data is available.
- Commit to save, or Revert to discard draft changes.

Set Builder does not move real macOS menu bar icons, replace the system menu bar, or apply physical profiles.
