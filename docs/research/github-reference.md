# GitHub Reference Notes

This project may study public behavior and product UX patterns from existing menu bar utilities, but implementation must remain original.

## Reference Categories

- Hidden Bar and Dozer can be reviewed for user workflows and broad feature framing after verifying current repository licenses.
- Ice, Thaw, SaneBar, and similar projects must not be copied or closely adapted unless the project intentionally accepts their license terms.
- Source snippets, file structures, algorithms, and implementation-specific naming from GPL or source-available projects are out of bounds.

## Audit Rule

Before using any third-party code, record:

- Repository URL.
- Exact commit or release.
- License file contents at that commit.
- Whether reuse is allowed for this project.
- What was reused, if anything.

Phase 0 reused no third-party code.
