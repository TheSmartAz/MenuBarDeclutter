# New Item Workspace Assignment v0.1.8 Preview

New Item assignment can resolve a newly discovered hashed item reference by adding it to:

- The current Workspace.
- A selected Workspace.
- An existing Group.
- A newly created Group, optionally linked to a Workspace.
- A visible-only or manual-placement outcome.

Assignments mutate only MenuBarDeclutter-owned local Workspace/Group data. Safe Mode blocks mutating Workspace/Group assignments.
