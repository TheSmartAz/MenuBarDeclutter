# Groups v0.1.1

Status: Preview.

Groups organize locally discovered menu bar item identities for MenuBarDeclutter-owned UI surfaces. They do not merge third-party menu bar icons into a native system group.

## Implemented

- Create/edit/delete groups in Settings.
- Add items from Find Icon and Second Bar item actions.
- Search within the group panel.
- Protected group opening/reveal through Private Access when protected groups require authentication.
- Group panel/reveal commands route through Command Center.
- Group hotkey assignment helpers for open/reveal group.
- Schema-checked group import/export with protected-name and item-identity redaction by default.
- Optional group status items remain off by default.

## Deferred

- Smart suggested groups.
- Preferred zone/default action fields.
- Command-routed remove-from-group and assign-hotkey executors.
- Full profile-aware group visibility workflows.
