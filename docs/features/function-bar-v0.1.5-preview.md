# Function Bar v0.1.5 Preview

Function Bar in v0.1.5 is a Preview app-owned panel. It displays actions from the active Workspace. It does not replace the macOS menu bar, does not capture screen pixels, does not use Screen Recording, and does not take ownership of third-party menu bar items.

The Function Bar can render command items, group references, menu bar item proxy references, spacers, dividers, and deferred Info Strip placeholders. Proxy references degrade when Pro Discovery or Accessibility permission is unavailable.

The Set Switcher can switch the active Workspace and refresh Function Bar content. Switching still does not move real menu bar icons or apply physical profiles.
