# Set Builder v0.1.6 Preview

Set Builder in v0.1.6 is a Preview tool for arranging MenuBarDeclutter's app-owned Workspace and Function Bar items. It does not move real macOS menu bar icons or replace the system menu bar.

Set Builder can create, rename, duplicate, archive, switch, edit, commit, and revert Workspace drafts. Users can add commands, spacers, dividers, groups, and Pro-gated menu bar item proxy references.

Function Bar Preview refreshes from committed Workspace data. Set Builder changes do not apply physical profiles, start Info Strip, move real icons, or perform bulk icon moving.
