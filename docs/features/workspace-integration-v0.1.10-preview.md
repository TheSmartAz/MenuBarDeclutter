# Workspace Integration v0.1.10 Preview

Workspace Integration in v0.1.10 includes:

- Usage index for direct Workspace item references and Group references.
- Find Icon Workspace filters and badges.
- New Item assignment to Workspaces and Groups.
- Workspace-aware placement hint enrichment.
- Crowded rescue Function Bar fallback preference.
- Physical profile binding preview planning.
- Privacy-safe diagnostics.

It is local-only and Preview-gated. Basic Mode remains usable when all Preview and Pro features are disabled.
