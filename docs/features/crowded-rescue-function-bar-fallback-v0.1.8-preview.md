# Crowded Rescue Function Bar Fallback v0.1.8 Preview

Crowded Reveal Rescue can prefer the app-owned Function Bar when inline reveal is likely to be crowded and the Function Bar Preview gate is enabled.

Fallback preference options:

- Prefer Second Bar.
- Prefer Function Bar.
- Ask Every Time.
- Inline Only.
- Prefer Full Menu Bar Mode.

Safe Mode and missing gates degrade to inline reveal or non-mutating suggestions.
