## Current Product Status

Stable:

- Basic expand, collapse, toggle, reveal all, and always-hidden reveal.
- Permission-free `NSStatusItem` hiding and Guided Manual Arrange.
- Launch at Login after explicit opt-in.
- Privacy-safe diagnostics, backup/restore, health checks, recovery, and Safe Mode.

Preview:

- Pro Accessibility Discovery, Find Icon, Second Bar, Accurate Icons, Workspaces, Workspace Integration, Function Bar, Set Builder, linked/detached Groups, Info Strip, Placement Planner, New Item Inbox, Crowded Reveal Rescue, Profiles, Smart Triggers, Dynamic Hotkeys, Private Access, App Intents, URL automation, and import/export workflows.

Labs and Experimental:

- Menu Bar Spacing Labs remains Labs.
- Assisted Move / Icon Moving remains Experimental and disabled by default.

Deferred:

- Private/offscreen menu bar item capture, Apple Events control, Input Monitoring, network/cloud sync, telemetry, analytics, remote config, stable automated physical icon moving, and Developer ID distribution/notarization.
