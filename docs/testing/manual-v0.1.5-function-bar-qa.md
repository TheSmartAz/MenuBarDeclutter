# Manual QA - v0.1.5 Function Bar

Use this checklist on macOS 26+:

- Launch with Function Bar Preview disabled; confirm no Function Bar opens automatically.
- Enable Workspaces Preview and Function Bar Preview from Advanced.
- Open Function Bar from Settings and from the status menu.
- Confirm the active Workspace name and items render.
- Switch Workspace from the Set Switcher and confirm visible items refresh.
- Confirm command items route safely.
- Confirm proxy items degrade if Pro Discovery or Accessibility is unavailable.
- Enter Safe Mode and confirm Function Bar is suppressed while recovery surfaces remain accessible.
- Confirm no Accessibility prompt appears from Basic Function Bar usage.
