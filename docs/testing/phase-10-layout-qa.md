# Phase 10 Layout QA

## Steps

1. Start the app in Basic Mode.
2. Open Settings > Layout.
3. Confirm capacity estimate appears without Accessibility.
4. Enter Full Menu Bar Mode from Settings and from the status menu.
5. Confirm auto-exit works when enabled.
6. Add divider, thin spacer, and wide spacer items.
7. Command-drag app-owned spacers in the menu bar.
8. Hide spacer markers and confirm optional spacers remain app-owned.
9. Disable layout features and confirm layout automation stops.
10. Enter Safe Mode and confirm Full Menu Bar Mode exits and optional spacers
    hide.

## Expected

- No Screen Recording prompt appears.
- Basic Mode remains usable without Accessibility.
- Diagnostics include layout settings but no screen contents.
