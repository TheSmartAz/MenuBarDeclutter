# MenuBarDeclutter Native macOS Redesign

Generated: 2026-06-30

This proposal resets the frontend direction to a deliberately native macOS app
model. The mockups avoid custom app chrome, dashboard cards, decorative glass,
and marketing-style layouts. The design system is built from reusable macOS
templates that map directly to SwiftUI/AppKit surfaces.

## Native Template System

Use these templates across the app instead of designing each page separately.

| Template | Surfaces |
| --- | --- |
| Settings shell | All settings pages: native split view, sidebar, titlebar toolbar, search |
| Grouped settings form | Overview, Behavior, Layout, Search, Second Bar, Privacy, Automation, Advanced, About |
| Table + inspector | Menu Bar Items, Diagnostics, Hotkeys |
| Outline/list + detail editor | Groups, Profiles, Import / Export |
| Assistant / sheet | Onboarding, import dry run, destructive confirmations |
| Compact utility panel | Find Icon, Second Bar, group panels, layout suggestions |
| Native status menu | Control item menu and separator contextual menu |
| Status/progress state | Discovery, import/export, diagnostics, repair, permission checks |

## Implementation Direction

- Settings shell: `NavigationSplitView`, native sidebar, titlebar toolbar, `.searchable`.
- Forms: SwiftUI `Form`/grouped sections, standard `Toggle`, `Picker`, `Slider`,
  `Button`, `DisclosureGroup`, and `ContentUnavailableView`.
- Data views: SwiftUI `Table` or AppKit table/outline where needed, with a
  native inspector pane for selected-item details.
- Transient tools: AppKit `NSPanel`/popover presentation with search-first list
  content and footer actions.
- Status menu: pure `NSMenu` command groups, not custom-rendered SwiftUI.
- Keyboard and pointer: first-class focus rings, menu commands, shortcut
  discoverability, table selection, and native drag/drop behavior.
- Color: system blue for selection/actions, green only for privacy-safe/healthy,
  amber for permission/preview/experimental states, red only destructive/error.
- Materials: standard window/sidebar/titlebar materials only; no decorative glass
  cards inside content.
- Liquid Glass: adopt through Apple's native system materials and future SDK
  components. Do not simulate it with custom translucent dashboard cards.
